# Docs audit — 2026-09-24: what the source owes the docs

The second docs audit, after the 22 merges since `a6825224` (needsyou …
uxfix). Every file in `docs/*.md`, `README.md` and
`integrations/*/README.md` was held against the source; where a doc was
wrong it was fixed in its own commit on `docsaudit2`. This file lists the
other direction: places where a doc (or a source comment) promises
something the code does not do. The docs below were left as written.

## Source-side items

| # | where the promise is | what the code does | evidence |

## Checked and not filed

- CI's Windows `check` job sets `MNML_E2E_ALLOW_SHELL=1` for
  `mnml-zig test --gate`, which would run `/bin/sh` on a Windows runner —
  but none of the 52 files in `tools/gate.txt` has a `shell` step, so
  nothing reaches it.
- `src/commands/specs.zig`'s `"1141 specs, unique ids"` test repeats its
  `expectEqual` 54 times: one per merge's comment line, each bumped to the
  current count. Harmless.
