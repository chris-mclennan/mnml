# mnml 0.3.1

mnml 0.3.1 is a fix release: the Jira and Bitbucket integrations 0.3.0
offered could not read a single answer from their sites, and 0.3.1's
index offers the fixed 0.2.1 of both. It also carries what landed on
the editor in the day since 0.3.0 — session cycling, the dock on the
command line's row, the tree's connectors and workspace dot, and the
top bar's integration chips.

## Install

As for 0.3.0: the installers, Homebrew (`brew upgrade mnml`), winget,
the `.deb` / `.rpm` packages, or the archives by hand. Nothing about
the channels, the asset names or the config changed.

## Highlights

### Jira and Bitbucket read their sites again

Jira and Bitbucket compress their answers whenever the client offers
it, and Zig's HTTP client offers gzip, deflate and zstd by default.
Both integrations handed the compressed bytes straight to the JSON
parser, so every Jira pane said "the search answer was not JSON" and
Bitbucket's panes failed the same way. 0.2.1 reads the body through
the answer's content-encoding, as mnml's own HTTP client already did,
and a parse failure now names what it saw — the read error that cut
the body short, or the content-type, the size and the first bytes.

**Updating:** the Marketplace tab in 0.3.1 lists Jira 0.2.1 and
Bitbucket 0.2.1; an installed 0.2.0 reads *update available*. The
integrations are released on their own tags (`jira-v0.2.1`,
`bitbucket-v0.2.1`), so a shell `mnml-jira --install` from the new
archive works too.

### Session cycling

`ai.focus_next_session` / `ai.focus_prev_session` —
`ctrl+alt+pagedown` / `ctrl+alt+pageup`, or `]a` / `[a` with a count in
a vim editor — step through every Claude Code and Codex pane wherever
it is: a split, a stacked tab, another tab page, the bottom dock. Each
session's tab strip shows its place (`‹ 3/7 ›`) and so does a new
sessions chip on the statusline. The Claude and Codex chip menus open
a new session in a new tab or on a new tab page.

### The dock on the command line's row

`ui.dock.placement = .shared` (`:dock shared`, or *on command line* in
Settings) puts the launcher dock's items on the `:` row itself: always
up, no grip, no extra row. Typing never moves them; they step aside
only while a long command would reach them.

### The tree

Every row below the top level carries its connectors now, in a grey
you can see. The workspace dot marks the active workspace, and a click
on one switches to it.

## Changelog

CHANGELOG.md's `v0.3.1` section, which is the GitHub release body:

- **Jira and Bitbucket 0.2.1** — the gzip fix above; parse failures
  name what they saw; the index offers 0.2.1 of both.
- **Sessions** — session cycling across splits, tabs, pages and the
  bottom dock; `‹ n/m ›` on the strips and the statusline; new sessions
  in a tab or on a page, a worktree profile's included.
- **The frame** — `ui.dock.placement = .shared`; tree connectors on
  every row below the top level; the workspace dot follows the active
  workspace and switches on a click; *About* prints the build's own
  version.
- **Integrations on the top bar** — the chips sit three cells apart; a
  newly installed integration, however it was installed, starts off the
  bar and a reinstall keeps your choice; the rebuild chip is no longer
  hidden by the host's manifest rewrite.
- **Testing** — Jira and Bitbucket run against a fake that compresses
  its answers; the tour and the drive harness run with the update check
  off; corpus files for session cycling and the shared dock.
- **The website** — mnml.sh: the home page, downloads from the latest
  release, the docs, the release notes and nine recordings.
