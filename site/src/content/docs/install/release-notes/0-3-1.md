mnml 0.3.1 is a fix release. The Jira and Bitbucket integrations that
0.3.0 offered could not read an answer from their sites; 0.3.1 offers
the fixed 0.2.1 of both. It also carries what landed on the editor
since 0.3.0: session cycling, the launcher dock on the command line's
row, and a clearer file tree.

This release is 1 contributor over 86 commits since 0.3.0.

## Highlights

### Jira and Bitbucket read their sites again

Jira and Bitbucket compress their answers whenever the client offers
it, and both integrations handed the compressed bytes straight to the
JSON parser: every Jira pane said "the search answer was not JSON", and
Bitbucket's panes failed the same way. The 0.2.1 integrations read the
body through the answer's content-encoding, as mnml's own HTTP client
already did. If a site still answers with something that is not JSON,
the message now says what arrived: the content-type, the size and the
first bytes.

To update, open the Marketplace tab under INTEGRATIONS: an installed
Jira or Bitbucket 0.2.0 reads *update available*. See
[Marketplace](/docs/integrations/marketplace).

### Session cycling

`ai.focus_next_session` and `ai.focus_prev_session` step through every
Claude Code and Codex session wherever it is — a split, a stacked tab,
another tab page or the bottom dock. The keys are `ctrl+alt+pagedown`
and `ctrl+alt+pageup`, or `]a` and `[a` (with a count) in a vim editor.
Each session's tab strip shows its place, `‹ 3/7 ›`, and so does a new
sessions chip on the statusline. The Claude and Codex chip menus open a
new session in a new tab or on a new tab page. See
[AI sessions](/docs/features/ai).

### The dock on the command line's row

`ui.dock.placement = .shared` puts the launcher dock's items on the
`:` row itself: always visible, no grip and no extra row. Typing never
moves them; they step aside only while a long command would reach them.
Set it with `:dock shared`, or *on command line* in Settings.

### A tree you can read

Every row below the top level draws its connectors, a `│` while a
sibling follows and a `└` on the last child, in a grey that can be
seen. The workspace dot marks the active workspace with `●`, and a
click on another root's `○` switches to it.

What a 0.3.0 user notices. The full list is the

### Jira and Bitbucket 0.2.1

- A compressed answer is decompressed before it is parsed.
- A parse failure names what it saw: the read error that cut the body
  short, or the content-type, the size and the first bytes.
- The release index offers Jira 0.2.1 and Bitbucket 0.2.1.

### Sessions

- Session cycling across splits, stacked tabs, tab pages and the bottom
  dock, with `‹ n/m ›` on each session's tab strip and the statusline.
- New Claude Code and Codex sessions open in a new tab or on a new tab
  page from their chip menus, a worktree profile's included.

### The frame

- `ui.dock.placement = .shared`: the launcher dock on the command
  line's row.
- Tree connectors on every row below the top level.
- The workspace dot follows the active workspace, and a click on one
  switches to it. An extra root's *Switch to this workspace* switches
  directly.
- *About* prints the build's own version.

### Integrations on the top bar

- The integration chips sit three cells apart, the same rhythm as the
  right-panel toggle beside them.
- A newly installed integration starts off the top bar, however it was
  installed; its menu's *Show on top bar* puts it there, and a
  reinstall or update keeps what you chose.

### The website

- This site: the home page, downloads from the latest release, the
  docs, the release notes and short recordings of mnml at work.
